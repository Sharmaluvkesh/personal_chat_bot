# Featured Projects by Luvkesh

## 1. Personal RAG Chatbot
- **Description**: An interactive RAG (Retrieval-Augmented Generation) chatbot powered by Groq LLM (`llama-3.3-70b-versatile`), SentenceTransformers (`all-MiniLM-L6-v2`), FAISS vector store, and a FastAPI backend with a modern glassmorphic React UI.
- **Key Features**: Page-level source citations, document upload support (PDF, TXT, MD), instant fact editor, speech synthesis & input, and customizable persona responses.
- **Tech Stack**: Python, FastAPI, LangChain, Groq, SentenceTransformers, FAISS, React, Vite.

## 2. Paper AI & Research Assistant

- **Tech Stack**: Python, Machine Learning, NLP, LangChain, Vector Databases.

## 3. Full-Stack Web Applications & Tools
